# COSMOLAXI — etapa visual

Protótipo responsivo da central gamer educacional COSMOLAXI, com identidade Soft Galaxy. Esta etapa é exclusivamente visual e navegável; não há serviços de backend.

## Como testar

Abra `index.html` em um navegador moderno. Para servir localmente, também é possível executar `python3 -m http.server 8000` na raiz e acessar `http://localhost:8000`.

## O que está incluído

- Base do Explorador com quarto espacial ilustrado em CSS, avatar demonstrativo e portal interativo.
- Navegação entre a Base do Explorador e o Mapa Galáctico.
- Oito planetas com paletas e descrições próprias; selecionar um planeta exibe uma mensagem de demonstração.
- Nível, XP, cosmo-moedas e conquista com valores fictícios.
- Layout responsivo para desktop, tablet e celular, com suporte a preferência por movimento reduzido.

## Demonstrações e limites desta fase

Perfil, avatar, progresso, moedas e conquista são dados estáticos fictícios. Os planetas e opções de personalização não iniciam atividades reais. Não foram implementados cadastro/autenticação, banco de dados, notificações, IA, jogos ou conteúdo pedagógico. A fonte pode carregar do Google Fonts; sem conexão, haverá fallback para fontes do sistema.
